# DIO Lab Open Source — Repositório de Participação

Este repositório registra atividades realizadas no laboratório **DIO Open Source**.

## Classificação correta

- **Natureza:** laboratório educacional e contribuição open source.
- **Finalidade:** praticar Git, GitHub, forks, branches, commits e pull requests.
- **Posicionamento no portfólio:** evidência de participação e aprendizagem colaborativa.
- **Não representa:** produto autoral principal, sistema em produção ou projeto comercial.

## Competências exercitadas

- fluxo distribuído com Git e GitHub;
- criação de branch e commits;
- pull requests;
- colaboração em repositório comunitário;
- documentação em Markdown;
- boas práticas de contribuição open source.

## Observação sobre o tamanho do repositório

O volume de arquivos decorre da natureza comunitária do laboratório e não deve ser interpretado como código integralmente produzido pelo titular deste perfil.
